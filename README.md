## 👋 Soy Kort

Estudio software en México y desarrollo proyectos móviles, web y backend. Según lo que necesite construir, puedo pasar de una app en Flutter o Android a una interfaz en React, una API, una base de datos o una automatización con Python.

También exploro C++, inteligencia artificial y nuevas herramientas de desarrollo. Este perfil reúne los proyectos que decida publicar y su evolución.

## 🧩 Lo que encontrarás aquí

- Aplicaciones para **Android y iOS**.
- Plataformas web, paneles y experiencias interactivas.
- APIs, bases de datos e integraciones.
- Automatizaciones, prototipos y experimentos con IA.
