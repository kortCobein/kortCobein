## Sobre mí

Soy estudiante de software y desarrollador en formación. Me gusta llevar una idea desde el problema real hasta una aplicación que pueda probarse, mantenerse y usarse de verdad.

- 📱 Desarrollo aplicaciones multiplataforma con **Flutter y Dart**.
- 🤖 Trabajo con **Android nativo, Kotlin y Java** cuando el proyecto lo requiere.
- 🌐 Construyo interfaces y plataformas con **React, Vite y TypeScript**.
- ⚙️ Integro backends y datos con **PHP, Node.js, MySQL y MariaDB**.
- 🔌 Me interesan especialmente **Bluetooth Low Energy, sistemas offline-first y comunicación entre dispositivos**.
- 🧪 Priorizo cambios precisos, pruebas reales y documentación útil.

## Cómo trabajo

- Entiendo primero el problema y conservo lo que ya funciona.
- Prefiero cambios pequeños, verificables y bien documentados.
- Pruebo en condiciones cercanas al uso real antes de considerar una entrega terminada.
- Mantengo cada proyecto organizado para que pueda continuar creciendo.
